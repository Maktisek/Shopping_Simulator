# 📦 Forest Market

#### Are you a fan of Stardew Valley, do you love simple pixel art, or do you just like to unwind with free indie games? Then ***Forest Market*** is just for you! Conquer the Katzburg market and become a millionaire... or maybe a billionaire?



## 🤷‍♂️ What is ***Forest Market*** all about?
It's all about maximizing your profits and swimming in *Tony Francs* by flipping goods for a higher price than you bought them!

And the best part? You can unlock achievements called *goals*. Collect them all and prove you're a real pro!

## ℹ️ Why this game was created

Not only have I always wanted to build my own game, but this project was also born as a school assignment. The goal was to create a game using the Java ***Swing*** library.

## ⬇️ Installation and Launch Setup
To run ***Forest Market***, you'll need a system with Java installed (version 17 or higher) ☕ get 17+ Java [(here)](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)

Unlike my previous projects, this game doesn't run in the command line, you can just double-click and launch it like any other regular game.

### 🙍 What if I can't open the game?
- If you get a popup saying "A Java exception has occurred," you most likely don't have Java 17+ installed.
- If the game won't open at all and just handles it like a regular ZIP file, right-click the file, choose "Open with..." and select Java(TM) Platform SE binary.

## 💻 How to Play
The core gameplay loop is actually super simple. Just keep an eye on the shop prices VS the buying prices offered by NPCs. When a good flip opportunity pops up, buy low and sell high!

### ⏰ In-Game Time
The game doesn't use real-time progression; instead, it works on a day-by-day basis. That means you can take your time and decide exactly when you want to advance to the next day!

Each new day updates the product prices, deducts your taxes, and refreshes the NPC market offers.

### ⬆️ Upgrade System
By default, you can only buy _**10**_ products per day, sell _**5**_ products per day, and hold _**100**_ products in your warehouse. This is super limiting at first, but don't worry, you can boost these stats using upgrades. Just click the icon of the skill you want to level up, and if you have enough cash, the upgrade is yours.

### 🪽 Rebirth System
If you want to breeze through the game without hitting a wall, the rebirth system is your best friend.

With every rebirth, your stats get a permanent boost, your taxes reset, and you unlock new shops. And more shops mean way bigger money.

### 📁 Save System
What's the point of playing if you lose all your progress, right? Fortunately, that won't happen to you in ***Forest Market***. You can easily save your game anytime using the top menu bar in the main window.

Since the game is currently in version 1.0, it only supports a single save slot. If you save a new game, it will overwrite your old progress.

### 🏆 Chasing Goals
In the _**goals**_ section, you can check out all your completed and locked achievements. Completing a goal rewards you with cold hard cash, so it's time to start grinding!

### 🛒 Buying and Selling
Sure, hitting "BUY" gets you an item and "SELL" gets rid of it, but you need to factor in shipping times. If you buy an apple today, it won't arrive until tomorrow. Keep that in mind, because what if apples aren't in demand tomorrow, or what if the price drops?

Shops can also run out of stock, and NPCs might stop buying certain goods. You can check the available supply and demand in the popup table by clicking on the item's image.

### ✖️ Multipliers
On the top bar, you can toggle one of three multiplier buttons. Activating a multiplier speeds things up. For example, if you select the **_10x_** button, you'll buy **_10_** apples at once instead of just one. This handy trick works for upgrades too!

### 🚫 GAME OVER
There is only one way to lose the game: going completely bankrupt. If you run out of money, have no items left in stock, no pending deliveries, and no pending goal rewards to claim, it's game over.

If you go bust, your final stats will pop up, and your only options are to head back to the main menu to start fresh, or try to load your old save file (if you remembered to save!).

## 🖱️ Controls
As of version 1.0, keyboard support hasn't been added yet, so the entire game is played using just your mouse.
